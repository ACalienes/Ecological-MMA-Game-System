## Class structure (6 blocks)

### Block A (0:00-13:44): Straight-punch parry
Offense: lead or rear hand only, straight punches only (no hooks/loops), light contact, feints + level changes encouraged. Defense wins by parry alone. Coach corrals the offense toward the wall as a footwork advantage ("the environment is always a factor" — use it if the defender is retreating/ducking).
**Maps to `parry-the-straight.md`** — base rules already match almost word for word. **New:** the wall-herding-as-defender's-footwork-advantage cue isn't in the doc yet (currently only the *attacker* gets a shot/clinch threat at higher levels).

### Block A2 (13:44-19:43): Parry + counter required
Same game, but a bare parry no longer wins — defense must parry AND land any counter (any target, any limb) to win.
**Maps to `parry-the-straight.md` Level 5**, which already has an optional counter. **Divergence:** in class the counter was mandatory to win, not optional. Worth a level/variant edit.

### Block B (19:43-28:00): Lead-hand-only + takedown win condition
Offense restricted to lead hand only (any level, feints). Two ways to win: land the lead-hand strike, **or** connect to the defender's leg / get a double-under body lock (skips the strike requirement entirely). Coach states a general rule here: hand control/grabbing is always live for both players unless he says otherwise.
**No existing doc matches this combination.** `lead-hand-offense.md` doesn't have the leg/takedown alternate win; the takedown-entry docs (`open-space-takedown.md`, `pressure-to-takedown.md`) all start from an established clinch, not from lead-hand-only striking. **This reads as a new hybrid game** bridging lead-hand striking to a takedown entry. Also: "hand control is always live unless stated otherwise" isn't written anywhere as a standing default rule — candidate for a system-wide rule alongside the above-the-knee connection law.

### Block C (30:00-48:24): Tight-block combination game
Offense throws combos up to 3 strikes (mixed head/body, straight or angled). Defense uses parry + tight blocking together to absorb. Land any of the 3 → offense continues. Block all 3 → defense wins, roles swap. **Explicit correction mid-class:** if offense throws a combo and misses all 3, offense loses outright regardless of how good the defense was — students were "being too lax" about this. Environmental layer added partway: small 2-mat square, both feet leaving it = auto-loss for either player, AND you can now win by actively pushing/walking the opponent out of the square ("sumo them out"). Coach's stated design reason for the small perimeter: students were over-moving instead of solidifying their defensive shape ("hyper-movement is counterproductive to defensive foundation").
**Blends `tight-block.md` (block-only) and `close-range-defense.md` (block+parry, but scored not won)** — neither matches exactly since the class version combines parry+block AND has a real win/lose. **New:** the "miss all 3 = automatic loss" rule isn't stated in `tight-block.md`. **New:** "sumo out of bounds" as an active win condition, not just a foot-fault loss.

### Block C2 (49:00-59:16): Block + counter required
Same combo game, but blocking alone no longer wins — defense must block AND land a counter. Hand control/grips explicitly always live for both sides (grab wrists, frame, control distance).
**Maps to `close-range-defense.md` Level 4**, same divergence as A2: doc has the counter as optional/available, class made it mandatory.

### Block D (59:16-73:00): Turtle/scramble — "Go Turtle"
Starts already in referee's position: bottom player on hands-and-knees, top player has hip-and-shoulder control with hooks in (not a hands-off race). Bottom wins by standing all the way up, fully breaking contact, and turning to face (any partial re-grip, even diving for an ankle, means it's not broken yet). Top wins by breaking the bottom player's hips flat to the ground and holding top-level pressure ~2-3 seconds ("taking the back doesn't win" — must be hips-down, not just a back-take). Top player may not lock their own hands together. Strikes live for both. If bottom reverses to top mid-scramble, bottom also wins. Coached escape detail: use the wall as an ally, glue to it on hands/knees, then scaffold upright off it while peeling the top player's hooks off.
**Maps to `turtle-breakout.md` in name only** — the actual mechanics differ almost everywhere: different start (established control vs. hands-off race), different win condition (hip-pin duration vs. hand-connection-above-the-knee), a new "no self-locked hands" constraint on top, strikes live in the base game (currently only a pending, unconfirmed level in the doc), and a wall-assisted escape technique not present at all. **Reads as a distinct, harder variant — candidate for its own entry rather than an edit to the existing page.**

## Reusable coaching gold

1. **Wall-herding as a defensive footwork advantage** (Block A) — corral a retreating/ducking opponent to the wall using your own footwork, don't chase in open space.
2. **"Hand control is always live unless I say otherwise"** (Block B, restated in C2) — an implicit standing rule across nearly every striking game that has never been written down explicitly. Candidate for a system-level default rule.
3. **Miss-a-combo-and-you-lose** (Block C) — offense that throws a full combination and lands nothing loses the exchange outright, even against weak defense. A discipline rule against "fling and hope."
4. **Small-perimeter as a movement-discipline fix** (Block C) — explicit coaching rationale: shrinking the space is a deliberate tool to stop students from substituting footwork/movement for real defensive shape.
5. **Wall as an escape ally, not just a boundary** (Block D) — "glue" to the wall on hands and knees, then use it to scaffold upright while peeling hooks off, instead of fighting the escape from flat on the floor.
6. **Turtle pin duration** (Block D) — 2-3 seconds of hips-down top pressure is the explicit standard for a "real" pin versus a fleeting tilt/back-take.
